# Week 3 Lab

## Web Technologies Lab

This repository contains the HTML program completed during **Week 3** of the lab.

## Experiment

### 01 - Class Timetable

Created an MCA class timetable using the HTML `<table>` element.

The program demonstrates:

* `<table>`
* `<tr>`
* `<th>`
* `<td>`
* `rowspan`
* `colspan`
* `border`
* `cellspacing`
* `cellpadding`

The timetable contains morning and afternoon periods, breaks, lunch, and the subjects scheduled from Monday to Friday.
